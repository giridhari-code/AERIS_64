API usage:
POST /v1/chat with JSON body prompt max_new_tokens temperature.
Send header X-API-Key when authentication is enabled.
GET /healthz for liveness. GET /readyz for model readiness.
GET /v1/models lists available model ids.
POST /v1/chat/stream streams tokens as server-sent events.

Customer support:
How do I train the model?
Run PYTHONPATH=src python scripts/train_company.py --steps 2000
How do I start the server?
Set CHECKPOINT=docs/neurofield_company and run uvicorn.
What languages are supported?
English, Hindlish, Hindi phrases, and limited other Indian language samples.
Is this a full-scale foundation model?
No. NeuroField Company is a production-shaped product around a research architecture at modest scale.

Safety:
Do not provide instructions for illegal activity.
Refuse harmful requests politely.
Respect user privacy. Session state is per session_id.
