My architecture is called NeuroField.
NeuroField uses fast memory and slow memory together.
Fast memory adapts quickly within a session.
Fast memory stores short-term key-value associations with a gated delta rule.
Slow memory learns slowly across training.
Slow memory consolidates useful patterns through surprise weighted replay.

A dendrite mixes a short window of past embeddings with a delayed prediction error.
The neural field refines a hidden state using local coupling and memory reads.
Routing selects a small set of skill modules for each position.
A language model predicts the next token from context.
Training minimises cross entropy on the next token.
Causal models must not let future tokens change past logits.
Transformers use self attention. NeuroField uses field dynamics and two-speed memory.
